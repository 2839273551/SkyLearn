首次安装教程
1.将所有文件解压至网站根目录
2.在站点设置中设置伪静态
location / {
	try_files $uri $uri/ $uri.php$is_args$args;
}


需要全新安装 在install目录下删除安装锁 install.lock

3.进入confing/config.php设置数据库信息 
4.导入到数据库中
5.默认账号密码二次验证都是admin，此时你应该可以登录了

注意：你必须安装redis以及php的redis扩展
否则无法正常使用

请去数据库中修改默认的账号密码
去confing/config.php修改默认的二次验证密码

然后访问后台 找到网站管理-站长帮助 继续进行操作

CREATE TABLE `qingka_wangke_pchange` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
  `cid` varchar(32) NOT NULL COMMENT '商品分类ID',
  `kcname` varchar(255) NOT NULL COMMENT '商品名称',
  `oldprice` decimal(10,2) NOT NULL COMMENT '旧价格',
  `newprice` decimal(10,2) NOT NULL COMMENT '新价格',
  `updatetime` datetime NOT NULL COMMENT '变动时间',
  PRIMARY KEY (`id`),
  KEY `idx_cid` (`cid`),
  KEY `idx_updatetime` (`updatetime`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
